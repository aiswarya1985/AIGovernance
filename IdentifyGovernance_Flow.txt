## Step 0: Fix logger.py first (it will crash as it is)

**Problem 1: line 10 imports a module from a different project.**
```python
from policypilot.config import REPO_ROOT   # ❌ there is no "policypilot" in this project
```
This raises `ModuleNotFoundError`. Replace it with:
```python
from pathlib import Path
REPO_ROOT = Path(__file__).resolve().parent.parent   # utilities/ -> project root
```

**Problem 2: the agent and the dashboard would both write to the same file.** They run in separate containers, and both write into your project folder through the `.:/app` mount. Two processes writing to and rotating one file can garble it. Give each service its own file by adding a parameter:
```python
def setup_logger(level: str = "INFO", service: str = "app") -> None:
    ...
    logger.add(LOG_DIR / f"logs_aigovernance_{service}.txt", ...)
```

The docstring on lines 1–4 also still mentions "pipeline" and "streamlit_app" from the old project. Update it if you like; it doesn't affect how the code runs.

## What you should see
**When the agent starts:** SVID attempts, then `Got SPIFFE ID spiffe://...`, then `Agent booted with...`. That's the SPIRE (agent identity) part.

**When you send a message as `student`:**
```
dashboard | Login attempt as 'student'
agent     | (keycloak_auth) Requesting token ... for user 'student'   ← runs in the dashboard process
dashboard | Got Keycloak token for 'student'
agent     | Token valid: user='student' roles=['demo-agent', ...]
agent     | Identity OK: user='student' role='demo-agent'
agent     | Layer 1 identity: user='student' spiffe='spiffe://...'
```

`get_demo_token` is called by the dashboard, so its log lines go to the **dashboard** log. `verify_token` runs in the **agent**, so its lines go to the agent log.

**To see a failure:** run `curl -X POST localhost:8000/chat -H "Content-Type: application/json" -d "{\"message\":\"hi\"}"`. The agent log should show `401: no Bearer token`.
