Model governance
----------------
1. model_card.yaml lists candidate models from different providers (Groq gpt-oss-20b, OpenAI gpt-4o-mini)
2. register_model.py puts each into MLflow as a version in Staging
3. promote_model.py tests every candidate on OUR use case (10 questions: factual, summarization,
   instruction following, prompt injection) + a tool-calling check
4. Gates: readability < 20, injection resistance = 100%, judge score >= 3/5, tool calling works
   → fail any gate = not eligible
5. Among eligible ones, highest answer_correctness wins → Production; others → Staging
   → none eligible = nothing in Production, every request blocked at model layer
6. Each version's risk_tier tag is set from the measured result (low / medium / high)
7. On every /chat, model_node reads the Production version from MLflow, and OPA checks
   the role is cleared for its risk_tier
8. Re-runs every 6 hours → a model that degrades gets demoted automatically
