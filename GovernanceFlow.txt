   **>> Correction:** this is not done per request. The SPIFFE ID is fetched **once at agent startup** from the SPIRE socket and cached. Each request just reads the cached value.    **>> Correction:** OPA = Open Policy **Agent**, not "access". And this step only checks "not revoked" (kill switch). It does not check that the identity is "correct". The identity node before it hardcodes pass, which is one of the gaps you found.

8. open meta data - check PII columns to be masked
